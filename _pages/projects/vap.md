## 👋 About VAP

VAP is a general visual information annotation platform, which offers three levels of annotation functions, i.e. image-level, instance-level, and pixel-level.

## 🔖 Background

This project aims to build a Visual Annotation Platform (VAP) for basic computer vision tasks. The current VAP supports image-level, instance-level, and pixel-level annotation, which corresponds to the image classification, object detection, and semantic segmentation task, respectively.

This project is based on the postgraduate case-teaching curriculum construction project of Xidian University (XDU-PCTCC), and has been further developed into an independent project.
