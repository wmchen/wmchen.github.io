Version 0.1.1.released

released in 1 November 2022.

  • new: 放大、缩小、适应缩放图像

Version 0.4.0.released

released in 27 March 2023.

【重大更新】“图像分类标注”更名为“图像级标注”，“目标检测标注”更名为“实例级标注”，“实例分割标注”更名为“像素级标注”

平台经过一次规模较大的重构，当前版本与前序版本不兼容！！！

图像级标注

  • new 更新文件列表样式：文件列表中可显示所有图像的地址及标注情况

  • modify 取消多标签标注，仅支持单标签标注

  • modify 取消“删除图像”、“删除标签”按钮

  • modify 删除图像、标签方式统一改为：鼠标选中列表中的条目后，按下键盘“Delete”，完成删除

  • modify 更新当前标签列表样式，取消下拉列表和按钮。标注时，直接鼠标左键双击所有标签列表中的条目，即可为当前图像添加或替换标签

  • modify 更新标注文件构建方式

实例级标注

  • new 新增鼠标光标样式，提高用户体验

  • new 旋转边界框标注，增加旋转标识，使用旋转标识进行旋转操作

  • new 新增隐藏/显示标注的功能

  • modify 水平边界框标注期间，改为四个顶点均可调整位置

  • modify 取消“删除图像”、“删除标签”、”删除边界框“按钮

  • modify 删除图像、标签、标注方式统一改为：鼠标选中列表中的条目后，按下键盘“Delete”，完成删除

  • modify 标注文件中，旋转边界框改为保存四个顶点坐标

  • modify 更新标注文件构建方式

  • fix bug 旋转边界框标注调整大小时出现漂移

  • fix bug 缩放后继续标注可能出现已标注边界框漂移的现象

像素级标注

  • new 新增标注期间缩放图像的功能

  • new 新增隐藏/显示标注的功能

  • modify: 修改多边形标注策略，调用鼠标事件实时画点，显著提高响应速度

  • modify 取消“删除图像”、“删除标签”、”删除多边形“按钮

  • modify 删除图像、标签、标注方式统一改为：鼠标选中列表中的条目后，按下键盘“Delete”，完成删除

  • modify 更新标注文件构建方式

其他

  • fix bug vap/utils/load_images.py中代码存在微小错误，不影响软件使用（load_images.py已变更为image_operator.py）
